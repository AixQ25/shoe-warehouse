# 安卓客户端（开发中）

这是复用本项目 FastAPI 后端和唯一 SQLite 数据库的原生安卓客户端。手机只访问 `/api`，不保存或直接打开数据库。当前界面采用方案 B（深绿与亮黄的高对比样式）：首页只有“领取”“归还”两个作业入口；连接和设备设置收在“设置”中。领取进入后直接启动相机扫码，模具逐行加入清单；归还必须先扫描实际库位，再扫描模具。扫码状态固定显示在相机区域内，成功加入库位或模具时播放短提示音；扫码画面右上角可开关手电筒补光，离开扫码或切到后台时自动关闭。提交前核对清单，领取在此时选择目标产线。支持手动输入、清单移除、本机草稿和未确认提交的请求编号恢复。

2026-09-30 已按 `ui-simplify-preview.html` 精简首页与扫码页：移除品牌英文、首页说明、扫码步骤编号和常驻“扫描中”；扫码结果短暂显示在相机区域，手动输入默认收起，手电筒以图标显示。归还扫码时可更换库位；已有模具清单时会先确认清空。调试版已重新构建并覆盖安装到 PMM110。

首页新增“搜索”入口，可按款号、类别或码数查询，结果显示当前所在位置与状态；左上角显示选定的方案 B 图标。手机系统返回键在搜索、设置、扫码和提交核对页面按层级返回，扫码清单和待确认请求会保留。

## 开发连接

1. 电脑和手机连接可以互访的局域网。双击项目根目录的 `start-local.cmd`，会同时启动电脑网页 `5173` 和手机 HTTP 入口 `5174`；若只需单独补开手机入口，也可运行 `start-local.ps1 -Lan`。启动信息会打印电脑当前地址。安卓 **debug** 包在“更换服务器地址”填写 `http://电脑IP:5174`，无需额外安装 CA 证书。这个端口通过 Vite 代理到本机后端 8000；不要在手机上填 `localhost` 或直接填 8000。
2. 当前是可信局域网测试，debug 包允许 HTTP，原生相机扫码不要求网络连接使用 HTTPS。迁移到其他电脑后启动项目，并在 App 修改电脑地址；普通草稿清空重新扫码，待确认请求先在原地址核对。正式版仍要求 HTTPS。`start-mobile-https.ps1` 的 `5175` 入口保留为可选证书试验，不参与日常启动。
3. 登录现有账号；若手机尚未登记，输入手机名称并登记，然后在电脑端“系统管理”授权，回到 App 刷新授权状态。按后端现有行为，主动点击“退出”会清除设备 Cookie，重新登录后可能需要再次登记授权。
4. 首页点“领取”即打开相机扫描 `MOLD:编号`；点“归还”先扫描 `LOC:编号`，然后扫描模具。光线不足时可点相机画面右上角的“打开手电筒”。相机不可用时可手输准确编号。清单可去重和移除；领取在完成扫码后选择目标产线。扫码加入清单不代表库存已更新。
5. 提交前同步保存请求编号、清单和原服务器地址；更换地址后禁止向其他地址查询或重试旧单据。超时或断网后，先点“查询原提交结果”，需要重试时沿用原编号和原清单。旧版缺少服务器地址的草稿不能直接提交：普通草稿清空后重新扫码，待确认单据须先在原电脑核对请求编号。HTTP 与 HTTPS 地址也视为不同来源，不能直接转发待确认单据。

## HTTPS / CA 方案记录

2026-10-06 的代码审查曾把手机入口切到 HTTPS 5175，要求手机信任电脑生成的 CA。CA 是 HTTPS 证书的信任来源，不是另一个 App。2026-10-07 根据测试阶段及后续换电脑的需求恢复默认 HTTP 5174，取消安装 CA 的必需步骤；并未实施“把测试电脑 CA 打包进 APK”的提议，也未向 APK 放入证书或私钥。

如以后单独验证 HTTPS，运行 `start-mobile-https.ps1`，通过 USB 等可信方式把脚本显示的 `pilot-ca.crt` 传到手机，核对 SHA-256 指纹后安装为用户 CA，再使用 `https://电脑IP:5175`。CA 和私钥目前在电脑本地 `%LOCALAPPDATA%\mold-warehouse-dev\certs`，不会自动随项目迁移；更换电脑后若生成新 CA，需要重新配置信任。正式部署时再确定稳定地址、证书签发、信任分发和证书迁移方案，不把测试电脑证书作为固定发布依赖。

## 构建

用 `D:\soft\AndroidStudio` 打开本目录并同步，或者在此目录运行 `gradlew.bat :app:assembleDebug`。已在 Studio 内置 JDK 25 上验证 Gradle 构建通过。若在另一台电脑首次同步，Wrapper 会下载 Gradle 9.4.1 并核对 SHA-256。不要提交 `local.properties`、签名文件或私钥。

正式包的更换服务器入口由 `BuildConfig.CAN_EDIT_SERVER=false` 隐藏。构建时通过 Gradle 属性 `warehouseServerUrl` 设置正式 HTTPS 地址，例如 `-PwarehouseServerUrl=https://warehouse.example.internal`。正式地址、可信证书和发布签名需要在固定电脑部署时共同确定；当前配置不能作为已完成的正式发布方案。
