# 鞋模具仓库系统（开发中）

当前 U 盘目录用于携带源码和办公室试点 SQLite 数据库，不是仓库正式服务器，也不保存正式数据库。前端所有页面都读取后端数据库。仓库布局和各业务页沿用早期界面样式；启动只认 `office-pilot-data/warehouse.sqlite3`，不会自动创建空库、账号或样例模具。正式仓库使用前仍须完成独立主机部署、PostgreSQL 并发、HTTPS/安卓扫码、打印和备份恢复验收。

- [项目规划](项目规划.md)：业务规则、首版范围和验收用例。
- [项目进度](项目进度.md)：逐阶段已完成内容、验证结果和未验证事项。
- [前端说明](frontend/README.md)：界面与本机登录方式。
- [后端说明](backend/README.md)：试点数据库、迁移、API 和测试。
- [部署与备份草案](deployment/README.md)：开发/正式 Compose、内网证书、备份和现场验收。当前电脑没有 Docker，此部分尚未运行验证。
- [办公室试点导入说明](试点导入说明.md)：清空样例后的 CSV 填写、导入及贴标步骤。
- [办公室试点操作说明](办公室试点操作说明.md)：旧库迁入 U 盘、每天启停、换电脑、登录故障与备份。

换一台办公室电脑继续开发时，从 U 盘打开项目；试点数据库随 U 盘移动，但运行中的 U 盘不能拔出。每台电脑的 Python 依赖、日志和试点库备份仍在该电脑本地。开发试点和正式部署使用不同数据库；正式配置文件和数据卷应放在仓库固定主机的本地磁盘。

首次使用先在原办公室电脑双击 [import-office-data.cmd](import-office-data.cmd) 迁入旧库。此后双击 [start-local.cmd](start-local.cmd) 启动服务并打开 `http://127.0.0.1:5173/`；结束时双击 [stop-local.cmd](stop-local.cmd) 关闭并备份，再安全弹出 U 盘。电脑重启后需再次启动；原账号、密码和库存保存在 U 盘试点库中。启动失败时查看窗口报错以及 `%LOCALAPPDATA%\mold-warehouse-dev\logs` 中的日志。
