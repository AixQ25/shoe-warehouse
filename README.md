# 鞋模具仓库系统（开发中）

当前项目和唯一正在使用的 SQLite 数据库一起放在 U 盘。数据库路径始终相对于项目根目录，为 `office-pilot-data/warehouse.sqlite3`；以后把整个项目搬到电脑时，也随项目一起移动这份文件。前端所有页面都读取该数据库。首次启动若文件不存在，会创建空库并要求设置 admin 密码，不会生成样例模具。仓库实际投入使用前仍须完成 HTTPS/安卓扫码、打印、并发和备份恢复等现场验收；原 PostgreSQL/Compose 部署草案尚未按“整包移动”方案更新。

换一台办公室电脑继续开发时，从 U 盘打开项目；数据库随项目移动，但运行中的 U 盘不能拔出。每台电脑的 Python 依赖、日志和安全备份仍在该电脑本地，这些不是另一份正在使用的数据库。以后整包搬到仓库电脑前，需要先停服务并验收新的启动、备份和并发方案。

双击 [start-local.cmd](start-local.cmd) 启动。首次启动会创建空库，并请你输入两遍至少 12 字符的 admin 密码；此后用同一账号和数据库继续。浏览器打开 `http://127.0.0.1:5173/`；结束时双击 [stop-local.cmd](stop-local.cmd) 关闭并备份，再安全弹出 U 盘。电脑重启后需再次启动。启动失败时查看窗口报错以及 `%LOCALAPPDATA%\mold-warehouse-dev\logs` 中的日志。
